**Budget Reconciliation**: attach your plan and actuals (plus purchase orders, invoices, rates, or headcount if you have them), then pick a command or describe what you need.

| Command | What it does |
|---|---|
| `fpa-br start` | Profile your attached files, learn how they fit together, and run the first reconciliation |
| `fpa-br run` | Re-run with the saved setup, for example on next month's files |
| `fpa-br report` | Write the one-page report and the detailed workbook |
| `fpa-br drill <line>` | Show the GL entries behind one line or flag |
| `fpa-br thresholds` | See or change what counts as material or unusual |
| `fpa-br help` | This menu |

The skill doesn't edit your files. It writes each result to a new file and checks that each dollar sits in one bucket: posted, pending, open, or released.
