What is an Agent?

"Agents are custom AI personas you build through conversation in Quick. Each agent has its own instructions, knowledge sources, and capabilities."

Instructions identity

NameDisplay name for the agent
DescriptionShort summary of what it does
InstructionsBehavior, tone, scope, rules

Capabilities access

Web searchSearch the internet
ConnectionsSlack, Outlook, Jira...
SkillsWhich skills it can use
SpacesConnected data sources
DocumentsUploaded reference files
Agents work in chat or run on their own on a schedule.
They can only access the same resources and services that you have access to. You control what each one is allowed to do.

What are Tools?

"A tool is a single operation an agent can perform. Tools don't carry instructions or workflows. They execute when called."

Built-in

File ops, code execution, web search, image gen, documents, knowledge graph

Connectors

Slack, Outlook, Jira, Salesforce, Zoom, ServiceNow

MCP Servers

Custom tools via the open Model Context Protocol

Coding Agents

Kiro, Claude Code via Agent Client Protocol (ACP)

Permissions model: Skills declare which tools they need. Agents grant which tools are available.

Agents or Automations?

Agents REASON

Interpret, decide, adapt

Automations FOLLOW

Predefined, deterministic

Agent contains

Automations

Quick FlowsTask automation with predictable steps
Quick AutomateBusiness processes at scale

When to use each

AgentTask needs reasoning, judgment, or adapting to context
FlowsPersonal task with predictable steps (triage email, move data between apps)
AutomateBusiness process at volume requiring auditability (invoice processing, compliance)
