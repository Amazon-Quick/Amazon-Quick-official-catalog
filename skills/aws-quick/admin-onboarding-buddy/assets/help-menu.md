**Quick Admin Onboarding Buddy commands**

| Command | What it does |
| --- | --- |
| `aob help` | Show this menu. |
| `aob start` | Run the full onboarding: check the connector, then the suite, connectors and knowledge bases, extensions, and the test. |
| `aob deploy` | Guide the backend build and CloudFormation deployment. |
| `aob suite` | Set or switch the productivity suite. |
| `aob tools` | Set up action connectors and knowledge bases for the suite. |
| `aob extensions` | Offer the suite's extensions and record their status. |
| `aob test` | Run the read-only integration test and save a Word report. |
