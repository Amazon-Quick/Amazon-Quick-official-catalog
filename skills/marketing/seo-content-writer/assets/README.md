# SEO Content Writer

Creates SEO-optimized blog posts, landing pages, and website copy that rank on Google while converting readers into customers.

## Overview

This skill solves the problem of producing content that satisfies both Google's ranking algorithm and human readers. It conducts keyword research, analyzes the top-ranking competition, finds content gaps, and writes in-depth articles that exceed what currently ranks, matching your brand voice when it finds brand docs in local folders. It is for small business owners and marketers, and it extends Amazon Quick by turning a topic or keyword into a publish-ready, on-page-verified draft.

## Pre-requisites

- Outlook (cloud connector, cloud runtime, optional): ensure it is installed, you are signed in, and it is enabled.
- Slack (cloud connector, cloud runtime, optional): ensure it is installed, you are signed in, and it is enabled.

## Installation

1. In Amazon Quick on desktop, go to Customize > Skills, choose Browse more, select the Official tab, and search for the skill by name. Choose Install.
2. Install and enable any connectors listed in Pre-requisites above. For connector setup, see https://docs.aws.amazon.com/quick/latest/userguide/connections-desktop.html

## Getting started

Invoke the skill with a request like "write a blog post about [topic]", "help me rank for [keyword]", or "write a landing page". It will run keyword research, confirm your target keyword, and produce a draft; connect Outlook or Slack only if you want to share the finished article directly.
