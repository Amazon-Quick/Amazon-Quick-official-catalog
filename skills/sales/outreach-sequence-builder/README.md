# Outreach Sequence Builder

Adds multi-touch outreach sequences that combine email, LinkedIn, and phone scripts personalized to each prospect.

## Overview

Outreach Sequence Builder writes complete cadences with timing, subject lines, body copy, A/B variants for the first touch, and conditional branching logic. It is for small business sellers who want personalized sequences that read like a knowledgeable peer, not mass-market spam. It extends Amazon Quick by loading lead-prospector context when present, staging drafts for sending, and falling back to formatted text when no connector is available.

## Pre-requisites

- Outlook (cloud connector, cloud runtime, optional): ensure it is installed, you are signed in, and it is enabled.
- Gmail (cloud connector, cloud runtime, optional): ensure it is installed, you are signed in, and it is enabled.
- Zoom (cloud connector, cloud runtime, optional): ensure it is installed, you are signed in, and it is enabled.

## Installation

1. Download the skill and add it in Customize > Skills.
2. Install and enable the connectors listed above. For connector setup see https://docs.aws.amazon.com/quick/latest/userguide/connections-desktop.html and the per-integration guides at https://docs.aws.amazon.com/quick/latest/userguide/integration-guides.html . For MCP setup see https://docs.aws.amazon.com/quick/latest/userguide/mcp-integration.html . To add a skill see https://docs.aws.amazon.com/quick/latest/userguide/skills-desktop.html

## Getting started

Ask things like "write outreach emails", "create a sales sequence", "draft cold emails", or "build a cadence" to generate a sequence.
