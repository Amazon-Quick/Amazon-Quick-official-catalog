# Merchant Monday Briefing

Automated weekly performance intelligence that replaces dashboard reviews with synthesized insights and recommended actions for retail merchandising leaders.

## Overview

Automated weekly performance intelligence that replaces dashboard reviews with synthesized insights and recommended actions for retail merchandising leaders.

## Pre-requisites

This skill builds on the following built-in Amazon Quick system skills. They are pre-installed and marked with a System badge; make sure each is enabled in Customize > Skills (see https://docs.aws.amazon.com/quick/latest/userguide/skills-desktop.html):

- `highcharts`: builds interactive charts and data visualizations (a built-in Amazon Quick system skill).
- `html_design`: builds formatted HTML views and artifacts (a built-in Amazon Quick system skill).

## Installation

1. In Amazon Quick on desktop, go to Customize > Skills, choose Browse more, select the Official tab, and search for the skill by name. Choose Install.
2. In Customize > Skills, confirm the built-in system skills listed above are enabled (they carry a System badge and are on by default).

## Getting started

Use it when asked to 'give me my Monday briefing', 'weekly performance summary', 'what needs attention this week', 'category performance review', 'merchandising dashboard', or 'what happened last week in [category]'.
