# Skill Architect

Builds tested, reusable AWS Quick agent skills from a description, an agent prompt, or an existing workflow.

## Pre-requisites

The first step checks each dependency and stops when a required one is missing.

| Name | Type | Required |
| --- | --- | --- |
| [Code execution](https://docs.aws.amazon.com/quick/latest/userguide/system-tools-desktop.html) | SYSTEM_TOOL | Y |
| [Web Search](https://docs.aws.amazon.com/quick/latest/userguide/system-tools-desktop.html) | SYSTEM_TOOL | N |
| [Task management](https://docs.aws.amazon.com/quick/latest/userguide/system-tools-desktop.html) | SYSTEM_TOOL | N |

## Installation

Install the skill in AWS Quick, then set up each dependency above. See [Skills in AWS Quick](https://docs.aws.amazon.com/quick/latest/userguide/skills-desktop.html).

## Getting started

Enter `sa help` to see its commands.
