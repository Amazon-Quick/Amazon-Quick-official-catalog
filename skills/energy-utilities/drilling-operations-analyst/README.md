# Drilling Operations Analyst

Quantitative drilling performance analysis across the well lifecycle covering wellbore positioning, drilling efficiency, and economics.

## Overview

Quantitative drilling performance analysis across the well lifecycle covering wellbore positioning, drilling efficiency, and economics.

## Pre-requisites

This skill builds on the following built-in Amazon Quick system skills. They are pre-installed and marked with a System badge; make sure each is enabled in Customize > Skills (see https://docs.aws.amazon.com/quick/latest/userguide/skills-desktop.html):

- `canvas_xlsx`: creates Excel (.xlsx) spreadsheets (the built-in Spreadsheets system skill).
- `highcharts`: builds interactive charts and data visualizations (a built-in Amazon Quick system skill).
- `html_design`: builds formatted HTML views and artifacts (a built-in Amazon Quick system skill).

## Installation

1. Add this skill in Amazon Quick: https://docs.aws.amazon.com/quick/latest/userguide/skills-desktop.html
2. In Customize > Skills, confirm the built-in system skills listed above are enabled (they carry a System badge and are on by default).

## Getting started

Use it when asked to 'calculate a wellbore survey', 'run minimum curvature', 'compute MSE', 'analyze drilling efficiency', 'parse a daily drilling report', 'plot a mud weight window', 'track cost per foot', 'classify NPT', or 'benchmark wells against offsets', or any drilling optimization, trajectory, or well-planning analysis request
