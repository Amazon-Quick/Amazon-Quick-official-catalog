# Deal Pipeline Manager

Adds a fractional VP of Sales that reviews your pipeline, flags at-risk deals, prioritizes daily actions, and forecasts revenue.

## Overview

Deal Pipeline Manager assesses pipeline health, identifies stale and at-risk deals, ranks the highest-leverage actions to take, and forecasts revenue against a target. It is for owner-operators managing 5-50 active deals without a dedicated sales team. It extends Amazon Quick by pulling deal data from connected sources or verbal input, then producing prioritized coaching and skill-ready outputs for related sales skills.

## Pre-requisites

- Outlook (cloud connector, cloud runtime, optional): ensure it is installed, you are signed in, and it is enabled.
- Google Sheets (cloud connector, cloud runtime, optional): ensure it is installed, you are signed in, and it is enabled.

## Installation

1. Download the skill and add it in Customize > Skills.
2. Install and enable the connectors listed above. For connector setup see https://docs.aws.amazon.com/quick/latest/userguide/connections-desktop.html and the per-integration guides at https://docs.aws.amazon.com/quick/latest/userguide/integration-guides.html . For MCP setup see https://docs.aws.amazon.com/quick/latest/userguide/mcp-integration.html . To add a skill see https://docs.aws.amazon.com/quick/latest/userguide/skills-desktop.html

## Getting started

Ask things like "review my pipeline", "what should I work on today", "which deals are stuck", or "forecast my revenue" to run a morning, weekly, or full review.
