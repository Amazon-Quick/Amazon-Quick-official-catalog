# skill-architect

Builds tested, reusable AWS Quick agent skills from a description, an agent prompt, or an existing workflow.

## Overview

skill-architect builds each skill to the AWS Quick Skills Standard: a structured SKILL.md, supporting files, and evals. It plans the skill with you and builds it in sections you review. It then checks the skill against the standard and runs evals that compare results with and without the skill, and it tracks those results over time.

## Pre-requisites

None. skill-architect uses only tools built into AWS Quick: file operations, code execution, web search, and background tasks.

## Installation

In AWS Quick on desktop, go to Customize > Skills, choose Browse all, select the Official tab, and search for the skill by name. Choose Install. See [Browsing for more skills](https://docs.aws.amazon.com/quick/latest/userguide/skills-desktop.html).

## Getting started

Enter `sa help` to see its commands.
