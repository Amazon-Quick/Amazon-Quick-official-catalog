# Presentation Theme Creator

Create a custom PowerPoint theme with consistent colors, fonts, and slide layouts from style preferences.

## Overview

Create a custom PowerPoint theme with consistent colors, fonts, and slide layouts from style preferences.

## Pre-requisites

This skill builds on the following built-in Amazon Quick system skills. They are pre-installed and marked with a System badge; make sure each is enabled in Customize > Skills (see https://docs.aws.amazon.com/quick/latest/userguide/skills-desktop.html):

- `canvas_pptx`: creates PowerPoint (.pptx) presentations (the built-in Presentations system skill).

## Installation

1. Add this skill in Amazon Quick: https://docs.aws.amazon.com/quick/latest/userguide/skills-desktop.html
2. In Customize > Skills, confirm the built-in system skills listed above are enabled (they carry a System badge and are on by default).

## Getting started

Use it when the user says 'create a presentation theme', 'design my slide template', 'build a deck theme', 'custom PowerPoint template', 'presentation style', 'branded slide deck', or any request to generate a reusable slide template with custom visual identity.
