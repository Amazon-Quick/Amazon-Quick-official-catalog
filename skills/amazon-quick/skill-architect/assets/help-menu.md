The menu a skill renders on `<prefix> help`. The prefix is the skill's short initials (skill-architect is `sa`, api-design-helper is `adh`). One row per user-invocable workflow, derived from the skill's <Workflow> blocks and their triggers.

```markdown
**<Skill display name> commands**

| Command | What it does |
| --- | --- |
| `<prefix> help` | Show this menu. |
| `<prefix> <verb>` | One line from that workflow's description. |

Say a command to start, or describe what you want in your own words.
```
